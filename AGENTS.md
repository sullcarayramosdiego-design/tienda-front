# Design Context

This project uses the **Impeccable** design system helper. Refer to [PRODUCT.md](file:///d:/DD/frontend/PRODUCT.md) and [DESIGN.md](file:///d:/DD/frontend/DESIGN.md) at the project root for strategic and visual guidelines before making UI changes.

- **Register**: `brand` (Andean Vibes storefront & cultural guide)
- **Primary Palette**: Teal Andino (`#26a699` / `oklch(65% 0.16 174)`), Verde Campo (`#68bb6c`), Carmesí Suave (`#e18e96`).
- **Core Aesthetic**: Flat with Tonal Depth. Avoid heavy SaaS shadows, generic pastel cards, and overly rounded corners (max 10-16px).
- **A11y**: Ensure strict contrast (>= 4.5:1) and support `@media (prefers-reduced-motion: reduce)`.
