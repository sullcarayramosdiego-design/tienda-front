# Product

## Register

brand

## Users
Consumidores finales comprando productos con previsualización 3D. El objetivo es explorar productos y comprarlos en un entorno interactivo.

## Product Purpose
Proporcionar una experiencia de compra inmersiva ("TIENDA 3D EXPERIENCE") donde los clientes puedan interactuar con modelos 3D y realidad aumentada para tomar decisiones de compra informadas.

## Brand Personality
Elegante, minimalista y premium.

## Anti-references
No debe parecer una tienda genérica de plantillas. Evitar la saturación visual de colores e información excesiva.

## Design Principles
1. Mostrar, no solo contar: El modelo 3D es el protagonista, no el texto.
2. Interfaz silenciosa: La UI debe ser secundaria y discreta para que el contenido inmersivo resalte (estética premium/minimalista).
3. Elegancia accesible: La belleza visual no debe comprometer el acceso a usuarios con discapacidades.

## Accessibility & Inclusion
Soporte avanzado (WCAG AAA). Soporte estricto para la preferencia de reducción de movimiento (`prefers-reduced-motion`) y compatibilidad profunda con lectores de pantalla.
